## **JobTrack — Full-Stack Job Application Tracker**

Build a web app that helps users manage their job search.

Think of it as a personal dashboard where someone can track:

* Companies they're applying to
* Job positions
* Application status
* Interviews
* Deadlines
* Notes
* Contacts/recruiters
* Follow-up dates

Make it feel like a **real SaaS product**, not a school CRUD project.

### Example user flow

# Tech Stack

* **HTML + CSS + JavaScript**: Frontend
* **Firebase**: Hosting frontend (Static)
* **Visual Studio Code**: Frontend IDE
* **Java + SpringBoot**: Backend
* **Supabase**: Database (PostgreSQL) + Authentication
* **Render**: Hosting backend (SpringBoot API)
* **IntelliJ**: Backend IDE
* **GitHub**: Version control

# How this stack fits together

### Frontend

**HTML + CSS + JavaScript**:

```text
HTML
CSS
JavaScript
    ↓
Fetch API
    ↓
Java REST API
```

Don't use a frontend framework.

For example:

```javascript
async function loadApplications() {
    const response = await fetch(
        `${API_URL}/api/applications`,
        {
            headers: {
                Authorization: `Bearer ${token}`
            }
        }
    );

    const applications = await response.json();

    renderApplications(applications);
}
```

The frontend communicates with Java REST API using HTTP requests and JSON.

# Backend

**Java + Spring Boot**:

```text
jobtrack-backend/
│
├── controller/
│   ├── ApplicationController.java
│   ├── InterviewController.java
│   └── ContactController.java
│
├── service/
│   ├── ApplicationService.java
│   ├── InterviewService.java
│   └── ContactService.java
│
├── repository/
│   ├── ApplicationRepository.java
│   ├── InterviewRepository.java
│   └── ContactRepository.java
│
├── model/
│   ├── Application.java
│   ├── Interview.java
│   └── Contact.java
│
└── config/
```

Use Spring Boot to expose REST endpoints such as:

```text
GET    /api/applications
GET    /api/applications/{id}
POST   /api/applications
PUT    /api/applications/{id}
DELETE /api/applications/{id}

GET    /api/interviews
POST   /api/interviews
PUT    /api/interviews/{id}

GET    /api/contacts
POST   /api/contacts
```

A very recognizable Java backend architecture.

# Authentication

Use Supabase Auth so users can:

```text
Sign Up
   ↓
Log In
   ↓
Dashboard
   ↓
Only see their own applications
```

Database records can be associated with the authenticated user's ID.

Demonstrate concepts like:

* Authentication
* Authorization
* User-specific data
* REST APIs
* Database relationships
* CRUD
* Error handling
* Input validation
